# Blender-Bfres-Engine
A tool to create BFRES files with custom game shaders. (release in a few days, preparing guide/polishing code)

<img width="1482" height="711" alt="image" src="https://github.com/user-attachments/assets/b3007041-5229-4926-a875-80315beda35f" />

This tool is currently aimed at MK8D with more games in progress.

Supports:
- Viewing and previewing glsl shaders/materials which will output as bfres/bfsha binary files.
- Viewing AGL effects such as light prepass, bloom, shadows, and color correction.
- Basic importing of bfres. This is mainly aimed for games supported by the bfres engine, but should work on any Switch bfres.
- Customizable material UI via json which can edit shader uniform/macro data. There are plans for custom shader graphs in a future update to generate/build more code.
- Exporting as .bfres. This will only work for the games supported.
- Exporting as .bgenv for MK8D.
- Can export as .szs for course models.

Supported Games:
- MK8D

Planned Games:
- MK8U
- BOTW
- TOTK
- SP3
